# ミュラー・リヤー錯視実験

ミュラー・リヤー錯視を測定し、主観的等価点（PSE）を求めるための Web アプリです。ブラウザで開くだけで動作します（サーバー不要）。

**公開ページ: https://sasekazu.github.io/muller-lyer-experiment/**

## 使い方

1. **画面の校正（初回のみ）**
   最初に Ctrl+0（Mac は ⌘+0）を押し、そのあとは拡大・縮小をしないでください。学生証・運転免許証・クレジットカードなどを画面に重ね、青い四角の左右の縦線がカードの縁に合うようにスライダーを動かして「決定」を押します。
2. **θ を選ぶ**
   画面上部のボタンで θ（60° / 120° / 180° / 240° / 300°）を選びます。順序は実験者に指示されたとおりにしてください。起動直後は 60° が選ばれているので、最初の θ が 60° でない場合はボタンで選び直してください。
3. **測定する**
   右の線をマウスでドラッグして、左の矢印の主線（8cm）と同じ長さに合わせ、「記録」を押します。各 θ で 8 回繰り返します（上昇・下降・下降・上昇・上昇・下降・下降・上昇の順）。
4. **結果を見る**
   「結果を表示」で表が開きます。表をドラッグして範囲を選び、Ctrl+C（Mac は ⌘+C）でコピーすると、Excel にそのまま貼り付けられます。

## ボタン

| ボタン | 動作 |
|---|---|
| 配置（横並び / 縦並び） | 標準刺激と比較線の並べ方を切り替えます（縦並びでは比較線は画面中央に固定され、左右に伸び縮みします）。記録は配置ごとに別々に保存・表示されます |
| 1つ戻す | 直前の記録を取り消します |
| 結果を表示 | 測定値の表を表示します |
| リセット | 選択中の θ のみ、またはすべての記録を消去します |
| 画面校正 | 校正をやり直します |

## 注意

- 刺激の大きさは校正で決まります。校正のあとにブラウザの拡大・縮小をしないでください。
- 外部モニターに移したときなど、画面が変わった場合は再校正してください。
- 測定値はブラウザ内にのみ保存され、どこにも送信されません。結果は表からコピーして各自で記録してください。
- 画面の幅が実寸で約 27.5cm 以上必要です。足りない場合は全画面表示にしてください。
